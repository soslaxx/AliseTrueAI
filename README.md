# 🌸 AliseTrueAI Client

> Клиентская часть и скрипт установки для подключения Яндекс Станций к приватной ИИ-платформе **AliseTrueAI** с поддержкой автономного написания кода, зрением (VLM), веб-поиском и персональным характером.

---

## ⚡ Установка на колонку в 1 команду

Подключитесь к колонке через **SSH** или **ADB shell** от имени `root` и запустите:

```sh
curl -sSL https://raw.githubusercontent.com/soslaxx/AliseTrueAI/main/install.sh | sh
```

### Что скрипт делает на колонке:
1. 🔍 **Определяет модель устройства:** Станция Мини 1/2 (с часами и без), Лайт 1/2, Миди, Станция 2, Макс.
2. 🔓 **Монтирует файловую систему в режим чтения/записи (`remount rw`)**.
3. ⚙️ **Перенаправляет `uniProxyUrl`** в `quasar.cfg` на приватный WebSocket-мост `ws://ot.soslaxx.xyz:8090/uni.ws`.
4. 🎵 **Настраивает звуковой тракт** (включая фикс `plughw:0,0` для Станции Мини 1).
5. 🛡 **Включает защиту от автообновлений (OTA Anti-Brick Lock)** через `/etc/hosts` (блокирует окирпичивание кастомной прошивки Яндексом).
6. 🛠 **Устанавливает CLI-утилиту `tyan`** в `/data/opt/bin/tyan` для диагностики и статуса.
7. 🔄 **Перезапускает Quasar `maind`** — колонка сразу подхватывает кастомный мост.

## 🛠 Команды утилиты на колонке

```sh
tyan status   # Проверить статус сети, подключение к Quasar и мосту
tyan code     # Посмотреть Device ID для привязки к боту
tyan restart  # Перезапустить службы Quasar
```
